# Hub submissions

Forecasts submitted to the [BDBV Modeling Hub](https://github.com/InsightNet-US/BDBV-Modeling-Hub) weekly round, and each team's metadata, as fetched by `bdbvhubrenewal compare-hub --fetch`.
`manifest.json` records the hub commit and the access date.
Only files whose team licence is CC0-1.0 or CC-BY-4.0 are kept here, gzipped and otherwise unchanged.
Each team's licence is in its `model-metadata/` file.
Cite the contributing teams as described there.
