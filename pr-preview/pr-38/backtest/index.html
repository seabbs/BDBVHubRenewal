    Backtest¶

    Forecasts made at past vintages, scored on what each later release reported.

    Every model is scored on the count each later release reports, and complete weeks are a secondary check (Evaluation). Weeks still being reported are shaded, with hollow points.

    Overall¶

    Each release with a later release is an origin. Every model is scored on the count each later release reports, with the count outstanding at the origin in each final-count forecast thinned binomially by the share expected to arrive by then under the delay fitted at the origin. Complete weeks are scored against the latest release (Evaluation). Relative WIS is against randomwalk on the forecasts both made, and every row counts them, \(n\). Zones have only the random walk models, run on each zone, and only the reported target (Health zones).
